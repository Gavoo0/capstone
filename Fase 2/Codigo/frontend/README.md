# Frontend

Aplicación de gestión de la Escuela de Conductores Futuro, desarrollada con React, React Router, Vite y Tailwind CSS.

Para instalar dependencias, configurar MySQL y ejecutar la plataforma completa, sigue las instrucciones del [README principal](../../../README.md). El backend compila este frontend y lo sirve en `http://localhost:4000`; para desarrollo con recarga en caliente, ejecuta `npm run dev` desde esta carpeta.
